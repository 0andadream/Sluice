How it works

  1. Agent proposes

    The model suggests one USDC move. It cannot approve it, name a recipient, or raise the cap.

  2. Contract checks

    sluice-0andadream.testnet checks the cap, the asset, the route, and the recipient. Preview is free and signs nothing.

  3. Only then it signs

    A signature is allowed only after that yes, and only with the live switches on. This site does not sign or spend.
